O que é o FarmacoMatch

O FarmacoMatch é uma aplicação web de página única construída com Streamlit que permite selecionar dois medicamentos e verificar se existe alguma contraindicação registrada para o uso concomitante deles.

Como funciona

Três passos rápidos para verificar a compatibilidade entre dois medicamentos.

1

Selecione os medicamentos

Escolha dois medicamentos nos menus suspensos da aplicação, lado a lado.

2

Clique em «Verificar»

A aplicação busca a classe farmacológica de cada um e consulta as interações registradas.

3

Veja o resultado

Card verde: sem contraindicação registrada. Card vermelho: existe contraindicação para a combinação.
